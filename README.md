# Moxxy

Расширение Chrome: группы вкладок и закладки на весь экран в виде карточек.
Обложка + заголовок; при наведении — описание, бейджи, галерея; правый клик (или «⋯») — действия:
открыть, свои кнопки (например, скачать), отметка «Скачано», обновить, конструктор карточки.

## Установка

1. Скачай `moxxy-<версия>.zip` из [последнего релиза](https://github.com/tuturuleo/moxxy/releases/latest) и распакуй в постоянную папку.
2. Открой `chrome://extensions`, включи «Режим разработчика».
3. «Загрузить распакованное» → выбери распакованную папку.
4. Открывай Moxxy иконкой расширения или `Alt+B`.

**Обновление.** Moxxy сам проверяет релизы раз в день — когда выйдет новая версия, на ⚙ появится точка,
а в «Общих» настройках — ссылка на zip. Распакуй его поверх той же папки и нажми ↻ у Moxxy в `chrome://extensions`.
Данные (кэш карточек, пресеты, отметки) при этом сохраняются.

## Сборка из исходников

```
npm install
npm run build      # → dist/ (её и загружать как распакованное расширение)
npm run release    # build + release/moxxy-<версия>.zip
```

`npm run dev` пересобирает на лету; после сборки — ↻ у расширения в `chrome://extensions`.

**Релиз.** Подними `version` в `package.json` и запушь в `main`: GitHub Actions соберёт расширение
и опубликует релиз `v<версия>` с zip. Версия и ссылка на репозиторий попадают в манифест из `package.json`.

## Как это устроено

- **Источники** — открытые группы вкладок Chrome (`chrome.tabGroups`) и закладки (`chrome.bookmarks`), читаются вживую,
  ничего не импортируется. Удаление / перестановка в Moxxy = то же самое в Chrome (удаление с «Отменить»).
  Закрытые сохранённые группы API Chrome не отдаёт — кнопка «В закладки» копирует группу в папку закладок.
- **Парсинг** (`src/lib/extract.ts`) — OpenGraph / meta / JSON-LD (рейтинг, год, жанр), затем блоки пресета.
  Открытые вкладки читаются на месте (с авторизацией), остальное — запросом с cookies пользователя.
  Фоновая вкладка открывается только по явному действию (⧉, «Догрузить пустые», ↻ у пресета «через вкладку»).
  Кэш карточек и уменьшенных обложек — в IndexedDB.
- **Конструктор карточек** («✎ Конструктор» или ✎ на карточке) — пресет для адресов сайта: любое число блоков
  (картинка, галерея, заголовок, описание, текст, бейдж, кнопки/ссылки), у каждого — CSS-селектор и вид,
  где его показать (обложка / при наведении / действия). Живое превью; элементы можно выбрать мышкой (⌖).
- **Дубликаты** — одна и та же страница в нескольких вкладках: значок «×N» и раздел в боковой панели.

## Разработка UI без установки

`node dev/serve.mjs` → http://localhost:5178 — собранный `dist` с фейковыми `chrome.*` и тестовыми группами
(`dev/mock-chrome.js`). Только для проверки интерфейса, в расширение не попадает.
